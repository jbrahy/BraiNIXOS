REM BraiNIX boot-object install -- types one line into the recoveryOS Terminal.
REM
REM The Flipper is a keyboard and nothing else: it cannot read the screen, and
REM it cannot hold the power button for One True Recovery. Its whole job is to
REM remove transcription errors from a long command typed with no shell
REM history and no copy-paste, which is where two of this project's failures
REM came from. See docs/operations/BRINGUP_PLAN.md.
REM
REM PRECONDITIONS -- all of them, or this types into the wrong place:
REM   1. The mini is in recoveryOS (hold power -> Options -> Continue).
REM   2. Utilities -> Terminal is open and FOCUSED.
REM   3. The Flipper is plugged into the mini, not into the laptop.
REM   4. as-install-boot-object.sh, the payload, and .admin are on the other
REM      volume's data partition.
REM
REM Everything it runs is in that script, which was reviewed before deployment.
REM This file deliberately contains no password and no destructive command.

DELAY 3000
REM Give the Terminal focus time; a dropped first character silently corrupts
REM the path and the command fails in a way that looks like a missing file.
STRING sh /Volumes/Data/Users/Shared/brainix-boot/as-install-boot-object.sh
DELAY 500
ENTER
